## 🌠 Proyecto destacado: Sigif

> **Administración integral de negocios, sin fricción.**

Ecosistema web y móvil para administrar empresas: inventario sincronizado en tiempo real, facturación electrónica, contabilidad centralizada y comunicación segura mediante API REST.

- 🔄 Sincronización Web ↔ App móvil
- 🗄️ PostgreSQL con Supabase
- 🔐 API REST segura
- ☁️ Desplegado en Vercel
- 📊 Reportes contables automatizados
